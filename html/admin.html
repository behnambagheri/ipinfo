About these counts

Each diagnostic GET counts once. Web means an HTML response; API means JSON or plain text. Requests include scripts and bots. Several people may share a source IP through a router or VPN.

Each site is shown separately. Tracking starts when enabled. Source-IP records are retained for 30 UTC reporting days, including today. Activity timestamps are displayed in your time zone.

Country and city are approximate IP geolocation. Provider is the network's ASN organization, which may identify a VPN or hosting company. Missing location data is shown as “Unknown.”
