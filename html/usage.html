Usage

Commands use this service's address. Responses below are illustrative; your results depend on the IP address being looked up.

Just the IP address

$ curl '{{ .Host }}'
127.0.0.1

$ http '{{ .Host }}'
127.0.0.1

$ wget -qO- '{{ .Host }}'
127.0.0.1

$ fetch -qo- '{{ .Host }}'
127.0.0.1

$ bat -print=b '{{ .Host }}/ip'
127.0.0.1

Country, city, and network lookup

$ curl '{{ .Host }}/country'
Elbonia

$ curl '{{ .Host }}/country-iso'
EB

$ curl '{{ .Host }}/city'
Bornyasherk

$ curl '{{ .Host }}/asn'
AS31337

$ curl '{{ .Host }}/asn-org'
Dilbert Technologies

As JSON

$ curl -H 'Accept: application/json' '{{ .Host }}'
# Or: curl '{{ .Host }}/json'
{
  "city": "Bornyasherk",
  "country": "Elbonia",
  "country_iso": "EB",
  "ip": "127.0.0.1",
  "ip_decimal": 2130706433,
  "asn": "AS31337",
  "asn_org": "Dilbert Technologies"
}

IPv4 and IPv6

Pass the appropriate flag to your client to select IPv4 or IPv6. With curl, use -4 for IPv4 and -6 for IPv6.

$ curl -4 '{{ .Host }}'
$ curl -6 '{{ .Host }}'
