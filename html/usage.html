Usage

Commands use this service's address. Responses below are illustrative; your results depend on the IP address being looked up.

Just the IP address

$ curl '{{ .Host }}'
127.0.0.1

$ http '{{ .Host }}'
127.0.0.1

$ wget -qO- '{{ .Host }}'
127.0.0.1

$ fetch -qo- '{{ .Host }}'
127.0.0.1

$ bat -print=b '{{ .Host }}/ip'
127.0.0.1

Country, city, and network lookup

$ curl '{{ .Host }}/country'
Elbonia

$ curl '{{ .Host }}/country-iso'
EB

$ curl '{{ .Host }}/city'
Bornyasherk

$ curl '{{ .Host }}/asn'
AS31337

$ curl '{{ .Host }}/asn-org'
Dilbert Technologies

As JSON

$ curl -H 'Accept: application/json' '{{ .Host }}'
# Or: curl '{{ .Host }}/json'
{
  "city": "Bornyasherk",
  "country": "Elbonia",
  "country_iso": "EB",
  "ip": "127.0.0.1",
  "ip_decimal": 2130706433,
  "asn": "AS31337",
  "asn_org": "Dilbert Technologies"
}

IPv4 and IPv6

This service supports both IPv4 and IPv6 and reports the address used to connect to it. curl's -4 and -6 flags choose the client's connection family; a VPN or proxy may forward that connection over a different family.
