What is counted?

These figures belong only to {{ .Site }}. Each diagnostic GET request counts once, including requests from browsers, curl, wget, scripts, and bots. Web means an HTML response; API means JSON or plain text. These are request counts, not unique visitors.

Assets, health checks, database metadata, statistics, HEAD, and OPTIONS requests are excluded. Error responses from diagnostic routes are included. No visitor IPs, lookup addresses, or complete User-Agent strings are stored in these counters.

Counts begin when tracking is enabled. Reporting failures can delay updates; requests that could not be recorded are absent from these figures.
